# JCB Bill Generator

A mobile-first billing, turnover tracking, and customer payment management application tailored specifically for JCB and earthmoving machinery owners.

Built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS v4**, and **Capacitor for Android**.

---

## 🚜 Key Features (Foundation)

* **Mobile-First & Touch-Optimized:** Designed for JCB owners working on sites, with large touch targets, high contrast, and industrial JCB styling.
* **Navigation Drawer & Three-Line Hamburger Menu:** Accessible from the top-right of the dashboard and every screen, navigating to all major sections.
* **Bottom Navigation Bar:** Instant thumb access to Home, Bills, New Bill, Customers, and Reports.
* **Hour-Meter Billing Engine:** Automatically computes billable hours from start & end hour meter readings, rates, extra charges (batta), and discounts.
* **Clear Payment States:** Dedicated visual states with distinct color indicators:
  * 🟢 **Paid**
  * 🟡 **Partially Paid**
  * 🔴 **Unpaid**
* **Prepared for Future Supabase Integration:** Modular typed schemas (`types/index.ts`) matching database tables for owners, vehicles, customers, and bills.

## 📱 Initial Pages & Routes

| Route | Page | Description |
|---|---|---|
| `/` | **Dashboard** | Owner & JCB machine info, Create Bill CTA, Today's Bills, Today's Turnover, Outstanding Amount, and Recent Bills |
| `/create-bill` | **Create Bill** | Hour meter calculation, customer picker, payment recording, and live invoice breakdown |
| `/bill-history` | **Bill History** | Searchable bill archive with status filters (Paid, Partially Paid, Unpaid) and detailed invoice modal |
| `/customers` | **Customers** | Customer directory with outstanding balance alerts, job stats, and add customer form |
| `/reports` | **Reports / Turnover** | Turnover metrics (daily, monthly, all-time), collection rate bar, machine hours, and work breakdown |
| `/owner-details` | **Owner Details** | JCB model, registration number, default hourly rates, UPI ID, and business details |
| `/settings` | **Settings** | Invoice prefix, regional language preferences, and cloud sync status |
| `/login` | **Login** | Mobile-first authentication screen with demo account credentials |

```
│   ├── assets/                # App icons & graphics

│   │   ├── bills/             # BillCard, etc.

│   │   ├── BillHistory/       # BillHistoryPage.tsx
│   │   ├── CreateBill/        # CreateBillPage.tsx
│   │   ├── Customers/         # CustomersPage.tsx
│   │   ├── Dashboard/         # DashboardPage.tsx
│   │   ├── Login/             # LoginPage.tsx
│   │   ├── OwnerDetails/      # OwnerDetailsPage.tsx
│   │   ├── Reports/           # ReportsPage.tsx
│   │   └── Settings/          # SettingsPage.tsx
│   ├── types/                 # TypeScript interfaces (ready for Supabase)
│   ├── utils/                 # Currency, date, and badge formatting helpers
│   ├── App.tsx                # React Router route registry
│   ├── index.css              # Tailwind CSS configuration
│   └── main.tsx               # Application entry point

├── index.html                 # Mobile-first viewport & theme setup
├── package.json               # Scripts & dependencies
├── tsconfig.json              # TypeScript root configuration
├── tsconfig.app.json          # TypeScript app compilation rules
└── vite.config.ts             # Vite + React + Tailwind v4 setup
```

## 🛠️ Development & Build Commands

### Start Local Development Server
```bash
npm run dev
```

### Build for Production (TypeScript Check + Vite Build)
```bash
npm run build
```

### Sync Web Assets with Android Platform
```bash
npm run cap:sync
```

### Open Android Project in Android Studio
```bash
npm run cap:android
```
